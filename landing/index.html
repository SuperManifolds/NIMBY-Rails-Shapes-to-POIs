This tool has retired

NIMBY ShapeToPOI is no longer needed.

This service converted KML and shapefiles into NIMBY Rails POI mods. As of the latest NIMBY Rails release, the game supports real map overlays natively — so approximating shapes with points of interest is obsolete.

Use Turnout instead. It renders your KML and shapefile data as actual overlays inside the game, not point clouds.

Go to Turnout on GitHub
